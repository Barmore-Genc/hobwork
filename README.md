# Hobwork

A small personal app development platform. You build tiny apps — "hobs", named
after the household spirits — that each get a handler, a database and optionally
a little web UI. Hobwork runs them in tiny VMs of their own, and serves the UIs
alongside its own.

Everything is reachable over MCP, so an AI agent can create, test, deploy and
debug a hob end to end.

Early work in progress, not ready for anyone else to run yet. See
[`docs/architecture.md`](docs/architecture.md) for how it works.
